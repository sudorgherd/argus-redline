## ANALOG_INPUT wiring gate

Power both boards off before connecting, changing, or removing any GPIO4
wiring. Use board power and common board ground only; no external supply.

Do not wire until the available passive components are recorded and a divider
calculation proves the GPIO4 node cannot intentionally exceed **2.5 V** across
the complete potentiometer travel. This is a conservative project test ceiling,
not an absolute rating or final production range. Verify the node with a
multimeter before every `analog` command. Do not approach 3.3 V.

Required before wiring:

- board-powered passive potentiometer/divider components with recorded values;
- common board GND;
- multimeter;
- calculated worst-case GPIO4 voltage at or below 2.5 V;
- optional 0.1 uF capacitor from GPIO4 to GND for measurement stability.

## Proposed physical sequence (do not execute during Step 12A)

1. Re-enumerate both COM ports.
2. Flash characterization Hub build only.
3. Confirm role, IDs, firmware, Wire Protocol, and characterization banner.
4. Flash characterization Node build only.
5. Confirm role, IDs, firmware, Wire Protocol, listening, and banner.
6. Establish and record a clean TEST/ACK baseline.
7. Run `caps` on each role and record the bounded three-entry registry.
8. Run DIGITAL_INPUT released, pressed, and released tests one action at a
   time; then verify short, long, very-long, and startup-held UI behavior.
9. Run indicator off/on, master-disable, radio-overlap, and feedback-overlap
   observations one action at a time.
10. Run `deny-remote` and `deny-interlock`; record status and unchanged request.
11. Power both boards off before adding GPIO4 wiring.
12. Record available component values and calculate a board-powered passive
    network whose complete adjustment range cannot intentionally exceed 2.5 V.
13. Connect common ground, divider/potentiometer wiper to GPIO4, and optional
    0.1 uF GPIO4-to-GND capacitor. Recheck wiring before power-on.
14. Power on, re-confirm normal radio behavior, and measure GPIO4 with a
    multimeter before every `analog` action. Never exceed 2.5 V.
15. Record raw, normalized, multimeter voltage, and duration at each point.
16. Remove power before changing or removing analog wiring.
17. Record 30 post-action TEST/ACK exchanges, reset behavior, and power cycle.
